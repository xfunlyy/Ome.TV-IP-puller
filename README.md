# Ome.TV-IP-puller
A script that allows you to pull whoever you connect to IP.

# How to Install.
Copy the script and put your api key where it says, "Put API Key here" and put your discord webhook where it says, "Put discord webhook here".
Then go to Ome.TV and open developer tools and go to the console and paste the script in there. And now you're good to get peoples IP's, State, And city.
